## 📌 Опис проєкту

**TBF-DDOS** — це потужний інструмент для тестування власних систем на стійкість до DDoS-атак. Він дозволяє:

- 📡 Проводити **UDP Flood**
- 🔄 Виконувати **TCP SYN Flood**
- 🌐 Тестувати **HTTP Flood**
- ⚡ Використовувати **багатопотоковість** для максимального навантаження

Інструмент створено для **адміністраторів** та **фахівців з безпеки**, щоб перевіряти свої системи та вчитися захищати їх.
